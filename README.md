# SubWatch — менеджер подписок

SubWatch — веб-приложение на Django для учёта подписок и контроля регулярных платежей.

## Возможности

- Добавление новых подписок.
- Редактирование и удаление подписок.
- Отображение стоимости и периодичности оплаты.
- Учёт статуса подписки.
- Поиск подписок по названию.
- Фильтрация по статусу и категории.
- Сортировка по названию, стоимости и дате следующего платежа.
- Расчёт ежемесячных и годовых расходов.
- Отображение количества активных подписок.

## Технологии

- Python
- Django
- SQLite
- HTML
- CSS
- Git и GitHub

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/sashakilya99/SubWatch.git
cd SubWatch
```

### 2. Создание виртуального окружения

```bash
python3 -m venv venv
```

### 3. Активация виртуального окружения

Для macOS и Linux:

```bash
source venv/bin/activate
```

### 4. Установка Django

```bash
python -m pip install django
```

### 5. Применение миграций

```bash
python manage.py migrate
```

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000/

## Структура проекта

- `config/` — настройки проекта Django и главные URL-маршруты.
- `subscriptions/` — приложение для управления подписками.
- `subscriptions/models.py` — модели данных.
- `subscriptions/forms.py` — формы для работы с подписками.
- `subscriptions/views.py` — обработка запросов и бизнес-логика.
- `subscriptions/templates/` — HTML-шаблоны.
- `subscriptions/static/` — CSS-стили.
- `manage.py` — утилита управления Django-проектом.

## Назначение проекта

Проект создан для упрощения учёта регулярных расходов, контроля активных подписок и планирования будущих платежей.
